# User Help Center Guides

> **Coverage:** one guide per customer-facing feature in [`../../01-business-and-strategy/14_feature_catalog.md`](../../01-business-and-strategy/14_feature_catalog.md); escalation per use case in [`./support-escalation-matrix.md`](./support-escalation-matrix.md).

## Getting started

| Guide | Summary |
|---|---|
| **Open an account** | Download app → sign up → verify ID (photo + liveness) → fund → done (~10 min). |
| **Add a card to wallet** | Cards → Add to Apple/Google Pay → verify. |
| **Set up a savings goal** | Save → Create goal → set target + auto-save rule. |
| **Enable passkeys** | Profile → Security → Add passkey (Face/Touch). |

## Payments

| Guide | Summary |
|---|---|
| **Send money** | Payments → Send → choose payee → amount → confirm. |
| **Pay a bill** | Payments → Pay a bill → select biller → amount → confirm. |
| **Schedule a payment** | Payments → Schedule → date + amount. |
| **Request money** | Payments → Request → link/share. |

## Cards

| Guide | Summary |
|---|---|
| **Freeze/unfreeze** | Cards → card → Freeze. Instant. |
| **Set limits** | Cards → Controls → set limits by channel. |
| **Report lost/stolen** | Cards → Report → replacement ordered. |
| **View PIN** | Cards → View PIN (after step-up auth). |

## Security & support

| Guide | Summary |
|---|---|
| **Spot a scam** | We warn on risky payments; slow down and verify. |
| **Dispute a transaction** | Transactions → transaction → Dispute → we investigate. |
| **Accessibility support** | Profile → Accessibility; request adjustments. |
| **Contact us** | Assistant (24/7) → human escalation anytime. |

## Troubleshooting

- **"Where is my transfer?"** → ask the assistant or check Payments → status.
- **Card declined** → we show the reason; retry or contact.
- **Can't log in** → use passkey or OTP fallback; recover via support.
