# North Star and Funnel Metrics

## North-star metric

**Monthly active customers completing at least one high-value digital journey** (payment, application, savings goal). This balances growth with genuine value.

## Funnel metrics

### Activation funnel
| Stage | Metric |
|---|---|
| Install → Sign up | Install-to-signup rate |
| Sign up → KYC | KYC completion rate, time-to-KYC |
| KYC → Funded | Funding rate |
| Funded → First payment | First-payment rate |
| First payment → Aha | Aha-event rate |

### Engagement funnel
| Stage | Metric |
|---|---|
| Weekly active | WAU/MAU ratio |
| Habit | 3+ active weeks/month |
| Depth | Products per customer |
| Retention | Month-1, Month-3 retention |

### Trust metrics
| Metric | Target |
|---|---|
| Fraud loss (bps) | ↓ 30–50% |
| False-positive decline rate | ↓ 40–60% |
| Complaint rate | Low & falling |
| Accessibility conformance | 100% |

## Counter-metrics (guard against gaming)

- Support contacts per 1k users (should fall, not rise).
- Chargeback rate.
- App-store rating and review sentiment.

## Reporting cadence

- **Daily:** ops dashboard (fraud, latency, errors).
- **Weekly:** product funnel + guardrails.
- **Monthly:** business review (north star, value pools).
