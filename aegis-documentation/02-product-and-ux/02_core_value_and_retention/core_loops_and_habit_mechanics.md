# Core Loops and Habit Mechanics

## Core value loops

### Loop 1 — Get paid → Sort → Save
1. Salary lands (trigger).
2. Auto-sort into pots (reward: effortless saving).
3. Visible progress toward goal (investment: engagement).
4. Repeat each payday (habit).

### Loop 2 — Spend → Track → Adjust
1. Customer spends.
2. Instant categorisation + notification.
3. Budget/insight updates.
4. Customer adjusts → feels in control.

### Loop 3 — Detect → Act → Trust
1. Fraud/anomaly detected.
2. Instant alert + one-tap freeze/confirm.
3. Resolution + reassurance.
4. Trust deepens → advocacy.

## Habit mechanics

| Mechanic | Use |
|---|---|
| **Cues** | Payday, bill due, low balance, large purchase |
| **Variable reward** | Cashback surprises, savings milestones |
| **Investment** | Goals created, external accounts linked, cards added |
| **Progress** | Visual goal bars, financial health score |

## Retention drivers

- **Switching cost:** linked external accounts, salary switch, multiple products.
- **Trust:** security reputation, transparent fees.
- **Habit:** daily balance check, payday automation.

## Anti-gambling guardrails

Avoid dark patterns (countdowns, loss-framing, variable-reward manipulation). Engagement must serve the customer's financial wellbeing, not extraction.
