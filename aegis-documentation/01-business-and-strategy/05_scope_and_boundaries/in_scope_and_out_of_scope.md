# In Scope and Out of Scope

## In scope (MVP → V3)

| Area | In scope |
|---|---|
| **Accounts** | Checking, savings, term deposits, joint, multi-currency, pots, salary sorting |
| **Payments** | Domestic, P2P, wires, standing orders, QR, cross-border, instant rails |
| **Cards** | Physical + virtual, freeze, granular controls, wallet provisioning |
| **Lending** | Personal loans, overdraft, BNPL, credit building |
| **Wealth** | Savings goals, robo-advisor, self-directed investing, retirement |
| **Security** | Biometrics, passkeys, MFA, real-time fraud, scam detection, card controls |
| **Service** | Agentic assistant, live chat + human escalation, disputes |
| **Compliance** | KYC/KYB, sanctions/PEP, AML monitoring + SAR, audit trail |
| **Accessibility** | WCAG 2.2 AA |
| **Business (lite→full)** | Business accounts, invoicing, expenses, accounting integrations, payroll |

## Out of scope (v1)

| Area | Why out |
|---|---|
| **Full mortgage origination** | Complex, regulated; V3 |
| **Crypto trading/custody** | Emerging risk; V3 |
| **Insurance underwriting** | Partner-dependent; V3 |
| **Private banking (HNW)** | Different operating model; later |
| **Merchant acquiring** | Payments acceptance is a separate business; later |
| **Physical branch network** | Digital-first |
